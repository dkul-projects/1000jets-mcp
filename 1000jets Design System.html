1000jets · Design System v1

Private aviation, made legible.

A design language for a transparent, technology-first jet marketplace — trustworthy enough for a CFO, fast enough for a founder booking from their phone. Built on restraint: one confident serif moment, disciplined data typography, and a navy-and-brass palette that reads premium without shouting.

Color

Navy for trust, brass for premium, teal for transparency

Gold was replaced with a warmer, less caution-yellow brass — it reads luxury in print and on screen without competing with semantic amber. Navy deepens toward an almost-black for dark mode instead of flat charcoal, so night mode still feels like the brand.

Typography

Fraunces for arrival, Inter for the flight, Plex Mono for the numbers

Fraunces replaces the more generic Playfair Display — same editorial confidence, but its soft optical-size curves feel less "wedding invitation," more considered. Reserve it for moments; the product itself runs on Inter.
